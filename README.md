# pzmm

**pzmm** (Project Zomboid Mod Manager) — бесплатный мод-менеджер для игры
*Project Zomboid*. Позволяет скачивать моды из Steam Workshop, автоматически
устанавливать их в папку игры, обновлять, удалять и анализировать сборку на
предмет отсутствующих зависимостей и конфликтов файлов.

## Возможности

- **Загрузка модов из Steam Workshop** — по одному или пакетом из очереди.
- **Авто-установка** скачанных модов в папку `Zomboid/mods` (с возможностью отключить).
- **Обновление** уже скачанных модов одной кнопкой.
- **Удаление** выбранных или всех модов из папки игры.
- **Просмотр установленных модов** с разбором зависимостей (`require` из `mod.info`)
  и статусом: все зависимости удовлетворены или какие именно отсутствуют.
- **Глубокий анализ сборки** — отчёт о стабильности: количество модов, отсутствующие
  зависимости, конфликты файлов (перезапись `client`/`server`/`scripts`) и ошибки
  из `console.txt`.
- **Траблшутинг** — быстрая диагностика логов, очистка кэша Lua и старых логов.
- **Автоопределение путей** — Steam, папки загрузок, Workshop и модов игры
  (включая не-Steam / «пиратские» установки).
- Тёмная тема оформления, встроенный браузер мастерской.

## Требования

- Python 3.10+ (проверено на 3.14).
- Пакеты: **`PyQt6`** и **`PyQt6-WebEngine`**.
- Установленный **SteamCMD** (для скачивания модов). Можно указать путь вручную
  или положить `steamcmd.exe` в одну из стандартных папок — тогда он найдётся
  автоматически.
- Аккаунт Steam (анонимный вход тоже работает, но некоторые моды могут требовать
  авторизации).

> Примечание: в старых версиях README упоминался `requests` — фактически он не
> используется, достаточно PyQt6 + PyQt6-WebEngine.

## Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/0xSPRK/pzmm
cd pzmm

# 2. Установите зависимости
pip install PyQt6 PyQt6-WebEngine

# 3. Запустите
py pzmm.py
```

Также можно запустить модуль напрямую:

```bash
python -m pzmm
```

## Сборка исполняемого файла

Проект поставляется с конфигом [PyInstaller](https://pyinstaller.org/) —
`pzmm.spec`. Для сборки автономного `.exe`:

```bash
pip install pyinstaller
pyinstaller pzmm.spec
```

Результат появится в папке `dist/pzmm/`. Собранный бинарник не требует установки
Python на целевой машине (кроме самого SteamCMD).

## Первоначальная настройка

Откройте окно настроек кнопкой **«Настройки»** (шапка окна) и заполните пути.
Кнопка **«Автоопределить пути»** подставит всё сама, если Steam установлен
стандартно.

| Поле | Назначение |
| --- | --- |
| `steamcmd.exe` | Путь к SteamCMD. Если пусто — ищется автоматически. |
| Папка загрузок (root) | Корень, куда SteamCMD качает данные. Если пусто — берётся из папки `steamcmd.exe`. |
| Папка Workshop (108600) | Папка `steamapps/workshop/content/108600`. Пусто = автоопределение. |
| Папка `Zomboid/mods` | Куда устанавливаются моды. По умолчанию `~\Zomboid\mods`. |
| Авто-установка в игру | Сразу копировать скачанное в папку модов игры. |
| Логин / Пароль Steam | Для модов, требующих авторизации. Анонимный вход по умолчанию. |
| Язык интерфейса | `ru` (основной). `en` в разработке. |

Настройки хранятся в `%APPDATA%/pzmm/settings.json`. При первом запуске
старая конфигурация из папки рядом с исполняемым файлом переносится автоматически.

## Интерфейс

### Вкладка «Мастерская»

Встроенный браузер на движке Chromium показывает Steam Workshop.
Доступные действия:

- **«В очередь»** — добавляет ID мода с текущей страницы (из URL вида
  `...?id=123456789`) в список загрузки. Дубликаты игнорируются.
- **«Скачать очередь»** — скачивает все моды из списка и очищает его.
- **«Обновить скачанные»** — перескачивает все моды, уже присутствующие в папке
  Workshop (для обновления до актуальных версий).
- **«Убрать из очереди»** — удаляет выбранный ID из списка.

По завершении загрузки моды при необходимости автоматически устанавливаются
в папку игры. Ход процесса и логи отображаются в отдельном окне консоли.

### Вкладка «Установленные моды»

Таблица всех модов, найденных в папке `Zomboid/mods`:

| Колонка | Описание |
| --- | --- |
| Название мода | Имя из `mod.info`. Для мультиверсионных сборок показываются суффиксы версий в `[ ]`. |
| Внутренний ID | Внутренний идентификатор мода. |
| Требуемые моды | Список `require` из `mod.info`. |
| Статус зависимостей | `Ок` / `Все установлены` (зелёным) или `Нет: <список отсутствующих>` (красным). |

Кнопки: **Обновить список**, **Открыть папку**, **Удалить выбранные**,
**Удалить все** (с подтверждением).

### Вкладка «Траблшутинг»

Инструменты диагностики и «быстрого лечения»:

- **Анализ console.txt** — читает последние 10000 строк `~Zomboid/console.txt`
  и выводит уникальные ошибки (`ERROR:`, `Exception`, `STACK TRACE`,
  `failed to load`).
- **Глубокий анализ сборки** — сканирует установленные моды и формирует отчёт:
  - общая статистика (количество модов);
  - отсутствующие зависимости (какой мод требует то, чего нет в сборке);
  - конфликты файлов — моды, меняющие одни и те же `client`/`server`/`scripts`
    файлы (поздний загрузится поверх раннего и «сломает» его);
  - счётчики критических ошибок и предупреждений из `console.txt`.
- **Очистить кэш Lua** — удаляет `~Zomboid/Lua`. Помогает, когда после обновления
  модов «поедет» интерфейс игры (кэш пересоберётся заново при следующем запуске).
- **Удалить старые логи** — удаляет `~Zomboid/Logs` (и `logs`) и `console.txt`,
  освобождая место на диске.

## Как это работает

1. **Загрузка.** `core/steamcmd.py` (`SteamCmdService`) запускает `steamcmd.exe`
   с командами `+workshop_download_item 108600 <id>` для каждого мода и парсит
   его вывод, чтобы понять, скачался ли предмет или упал с ошибкой. Поддерживается
   таймаут зависания и принудительная остановка.
2. **Установка.** `core/installer.py` (`install_item`) копирует содержимое папки
   `<workshop>/.../<id>/mods` в `Zomboid/mods`. Владение файлами ведётся
   централизованно: один глобальный манифест `manifest/manifest.json` хранит
   для каждого файла список модов-владельцев. Файл физически удаляется только
   когда ни один мод больше не ссылается на него — поэтому удаление одного мода
   не «сломает» файл, который всё ещё нужен другому.
3. **Сканирование.** `core/registry.py` + `core/mod_parser.py` обходят папку модов,
   читают `mod.info` (с учётом BOM) и группируют записи по `(корневая папка, id)`,
   собирая версии и пути к `media`.
4. **Анализ.** `core/analytics.py` (`AnalysisWorker`, в отдельном потоке)
   строит HTML-отчёт о стабильности сборки.
5. **UI.** `ui/` — PyQt6-виджеты, тёмная тема в `ui/theme.py`, локализация
   в `core/localization.py`.

Архитектура слоистая: `UI → core (settings / downloader / installer / registry /
steamcmd / analytics) → внешний SteamCMD`. Точка входа — `pzmm/__main__.py`
(или `pzmm.py` для совместимости).

## Структура проекта

```
pzmm/
├── __main__.py              # точка входа (python -m pzmm)
├── pzmm.py                  # совместимость: python pzmm.py
├── pzmm.spec                # конфиг PyInstaller
├── pzmm/
│   ├── core/
│   │   ├── settings.py      # настройки, резолв путей, автодетект Steam
│   │   ├── steamcmd.py      # обёртка над steamcmd.exe
│   │   ├── downloader.py    # DownloadWorker (поток загрузки + автоустановки)
│   │   ├── installer.py     # синхро-установка с ref-count манифестом
│   │   ├── mod_parser.py    # парсинг mod.info
│   │   ├── registry.py      # сканирование установленных модов
│   │   ├── analytics.py     # глубокий анализ сборки (поток)
│   │   └── localization.py  # словарь строк + загрузка языка
│   └── ui/
│       ├── main_window.py   # главное окно, навигация между вкладками
│       ├── workshop_tab.py  # браузер мастерской + очередь
│       ├── mods_tab.py      # таблица модов и зависимостей
│       ├── trouble_tab.py   # траблшутинг
│       ├── settings_dialog.py
│       ├── console_dialog.py# окно лога загрузки
│       └── theme.py         # тёмная QSS-тема
├── locales/
│   └── ru.json             # русская локаль (эталонный словарь)
└── tests/
    └── test_core.py        # юнит-тесты ядра
```

Запуск тестов:

```bash
python -m unittest tests.test_core -v
```

## Локализация

Основной язык — **русский** (`ru`). Файл `locales/ru.json` содержит эталонный
словарь; при первом запуске он копируется в `%APPDATA%/pzmm/locales/`.
Переключатель языка есть в настройках, но на данный момент доступен только
русский (английский — в разработке, см. таблицу внизу README).
